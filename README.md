## Description

This project is about creating a simple shell. We separated the task in 2.
rvasseur did the exec while kislamov did the parsing. It act as a simple shell,
the user can try builtins command like ls, cd. extern command like /bin/ls.. that are in the path.


## Instructions

compile with
```bash
make
```

and start it with
```bash
./minishell
```

then it can be use as a bash shell:
```bash
minishell> ls
```
